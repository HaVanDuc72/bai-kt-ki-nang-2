# Smart Canteen Management System

## Giới thiệu

Smart Canteen Management System là hệ thống quản lý căng tin trường học được xây dựng bằng Python Flask và SQLite, hỗ trợ quản lý món ăn, nguyên liệu, nhà cung cấp, bán hàng và phản hồi khách hàng.

Hệ thống tích hợp AI nhằm hỗ trợ phân tích dữ liệu và đưa ra các đề xuất.

## Chức năng

- Đăng nhập hệ thống
- Quản lý món ăn
- Thêm, sửa, xóa món ăn
- Tìm kiếm món ăn
- Quản lý nguyên liệu
- Quản lý nhà cung cấp
- Quản lý bán hàng
- Quản lý phản hồi khách hàng
- Báo cáo và thống kê
- Phân tích và đề xuất bằng AI

## Công nghệ

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Google Gemini AI
